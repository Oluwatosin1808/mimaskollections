# Mima's Collections

Ecommerce website for an SME in Lagos, Nigeria — premium e-commerce storefront built with Next.js, TypeScript, and TailwindCSS.

## Features

- App Router pages with SEO-first metadata
- Luxury black and gold visual system
- Responsive category and product grid layouts
- Owo-Flex financing page and service pages
- Sticky blurred navbar and premium hover interactions
- Loading skeleton states for transition readiness

## Scripts

- `npm run dev` - start local development
- `npm run build` - compile production build
- `npm run start` - serve production build
- `npm run lint` - run ESLint
